# Bounded native Codex outcome campaign

A single ChatGPT-authenticated included-allowance session used codex-cli 0.160.0, pinned gpt-6.1-sol with max reasoning, a read-only sandbox and ephemeral operation. It completed twelve synthetic tasks against an immutable prepared source snapshot, with actual native stdio MCP calls. No paid API fallback, credentials, customer system or operational action was used.

The implementation owner checked independent expected numeric facts, actual MCP receipts, retained owners/provenance, missing-evidence handling and artifact structure: 12/12 passed. This is bounded deterministic grading, not independent healthcare expert acceptance. The six valid cases use committed synthetic fixtures; separate clean-consumer and independent-review harnesses exercise different inputs. The model read the compact router and selected references and produced task-specific workplans/packet outlines rather than rubric scores.

Eleven actual MCP calls completed with six successful calculation results and one custom draft. Three calls returned BUSY when the model exceeded four concurrent calculations; the model retried those work successfully. One call returned CONTRACT_INVALID for the deliberately incomplete case. Failed tool calls are retained in the trace, not discarded. No protocol exception or substituted CLI calculation was needed. Routing was exercised through the actual CLI as specified.

The campaign took about 600 seconds and returned exit code zero just before its deadline. Native usage reported 323,137 input tokens, including 264,448 cached tokens, and 16,073 output tokens, including 8,642 reasoning tokens. These are session accounting totals across tool turns, not the size of one prompt. Remaining included quota and monetary cost were not measured; no token-saving claim is made.

[Machine-readable receipt](model-campaign.json) identifies runtime arguments, input/output hashes, source-manifest hash and checks. Full task files, prepared package source hashes, final artifacts and JSONL tool trace are retained in the immutable handoff bundle. No prepared source file changed during the model session. Subsequent successor edits and their separate release tests are recorded by the final commit/tree and handoff manifest; the campaign is scoped to its exact prepared snapshot.

Limits: one batched session rather than independent repeated trials; no source authentication, clinical certification, causal customer outcome, superiority comparison, native marketplace/plugin activation or remote ChatGPT web deployment. The generated documents remain review drafts with accountable human and evidence/action gates.
