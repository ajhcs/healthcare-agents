# Healthcare Admin Workflow Gallery

Healthcare Agents turns messy healthcare administration problems into structured workups with a primary specialist, handoffs, missing inputs, safety boundaries, and platform-ready prompts.

Quick start:

```bash
healthcare-agents workflows
healthcare-agents workup "Commercial payer denial rate jumped 18 percent after a policy change."
healthcare-agents workup "Prepare a HIPAA evidence checklist for a vendor security review." --target copilot
```
